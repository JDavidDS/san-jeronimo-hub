# Registro de decisiones (ADR)

Un archivo Markdown por decisión; conservar el historial. Copiar [0000-template.md](0000-template.md).

**Estados permitidos:** `Propuesta`, `Aprobada`, `Rechazada`, `Reemplazada`.

- Solo **David** puede aprobar o rechazar decisiones institucionales.
- Los agentes pueden redactar, analizar y proponer ADR; la aprobación debe quedar atribuida explícitamente.
- Una decisión reemplazada enlaza el nuevo ADR; no se elimina el documento original.
- Numerar secuencialmente `0001-titulo-corto.md`, `0002-...`.
- Toda decisión importante debe incluir fecha, opciones, motivos, consecuencias y referencias.
