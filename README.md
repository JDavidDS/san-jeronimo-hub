# San Jerónimo — Hub institucional

**Repositorio privado de contexto, decisiones y estado para el proyecto educativo San Jerónimo (Montería, Colombia).**  
Aquí colaboran personas y agentes de IA. **La fuente de verdad operativa es este hub**; los archivos institucionales originales y pesados permanecen en Google Drive; cada producto digital tendrá su propio repositorio.

## Cómo colaborar

1. Leer **AGENTS → CONTEXT → STATUS → decisiones relevantes** antes de actuar.
2. Crear o continuar un [Issue](.github/ISSUE_TEMPLATE/) con evidencia, alcance y entregables.
3. Tras esta inicialización autorizada, proponer cambios mediante **rama + pull request**. **Solo David integra a `main` y aprueba decisiones.**
4. Mantener **una fuente autoritativa por hecho**: enlazar documentos del [Drive institucional](https://drive.google.com/drive/folders/1ErImY2suayYLTT5SdfClOXQ69YJxt38H) en vez de duplicarlos.
5. Al cerrar trabajo, actualizar `STATUS.md` si corresponde y dejar un **handoff** para continuidad.

**Importante:** estar en preapertura y planificar programas no significa tener licencia ni registros aprobados. Los datos financieros, regulatorios y operativos reportados requieren contraste con sus soportes.
