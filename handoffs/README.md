# Handoffs entre agentes

Este directorio permite registrar entregas entre agentes cuando agregan valor a la continuidad del trabajo; no sustituye Issues, PR, ADR ni [STATUS.md](../STATUS.md).

1. Usar [templates/handoff.md](../templates/handoff.md).
2. Identificar agente, fecha, alcance y referencias a los archivos o PR.
3. Distinguir hechos terminados de propuestas o pendientes.
4. Evitar datos sensibles, duplicaciones y afirmaciones sin respaldo.
5. Si el agente no tiene acceso al repo, entregar el bloque HANDOFF en el chat para que un colaborador lo incorpore o abra un Issue.

Formato sugerido para guardar: `AAAA-MM-DD-agente-tema.md`. No modificar decisiones aprobadas desde un handoff.
